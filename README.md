# مدار آخر · Last Orbit

یک بازی آرکید فضایی تک‌نفره که مستقیم در مرورگر اجرا می‌شود؛ بدون حساب کاربری، دانلود دارایی‌های حجیم یا وابستگی به سرویس بازی.

## اجرا

```bash
npm install
npm run dev
```

برای ساخت نسخه‌ی نهایی و اجرای آزمون‌ها:

```bash
npm test
npm run build
npm run preview
```

## کنترل‌ها

- **W / A / S / D** یا کلیدهای جهت: حرکت
- **ماوس**: نشانه‌گیری؛ با نگه‌داشتن کلیک چپ شلیک کن
- **Space** یا **Shift**: دَش کوتاه و فرار از برخورد
- **Esc**: مکث یا ادامه
- در تلفن همراه: جوی‌استیک، شلیک و دَش لمسی

نشانه‌گیری کمکی به‌صورت پیش‌فرض روشن است؛ حرکت ماوس روی میدان بازی، نشانه‌گیری دستی را فعال می‌کند. رکورد، تعداد پروازها و مجموع دشمنان شکست‌خورده فقط در مرورگر خودت ذخیره می‌شوند.

## کیفیت و کارایی

- حلقه‌ی بازی با گام زمانی ثابت ۶۰ هرتز و سقف جبران فریم اجرا می‌شود تا بعد از مکث مرورگر، بازی جهشی نشود.
- وضوح Canvas با نسبت پیکسل دستگاه هماهنگ است؛ حالت «خودکار» در افت فریم وضوح رندر را پایین می‌آورد.
- افکت‌ها، ذرات، دشمن‌ها و پرتابه‌ها سقف مشخص و pool قابل‌بازیافت دارند؛ تعدادشان بی‌نهایت رشد نمی‌کند.
- تغییر اندازه‌ی Canvas، کنترل لمسی، مکث هنگام رفتن به پس‌زمینه، صداهای Web Audio و حالت تمام‌صفحه پشتیبانی می‌شوند.
- وب‌اپ پس از بازدید اول قابلیت نصب و اجرای آفلاین دارد.

## انتشار روی GitHub Pages

Workflow موجود در `.github/workflows/deploy.yml` بعد از push روی `main` یا شاخه‌ی کاری این جلسه، آزمون‌ها را اجرا می‌کند، نسخه‌ی Pages را می‌سازد و منتشر می‌کند. در تنظیمات مخزن، **Settings → Pages → Build and deployment → Source** را روی **GitHub Actions** قرار بده. چون نام مخزن `game` است، نسخه‌ی Pages با مسیر `/game/` ساخته می‌شود.

## فناوری‌ها

Vite، JavaScript مدرن، Canvas 2D و Web Audio API؛ بدون کتابخانه‌ی زمان‌اجرای سنگین.
